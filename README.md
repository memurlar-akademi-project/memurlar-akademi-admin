# Memurlar Akademi Admin

Next tabanli ayri admin istemcisi.

## Ilk kapsam

- admin auth
- dashboard
- bakanliklar
- sinavlar
- dersler
- konular
- sorular
- flashcardlar
- podcast
- denemeler
- paketler

## API

Varsayilan backend adresi:

- `http://127.0.0.1:8000/api/v1`

Istersen `.env.local` icine su degiskeni ekleyebilirsin:

```bash
NEXT_PUBLIC_API_URL=http://127.0.0.1:8000/api/v1
```
